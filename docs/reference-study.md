# Reference Study — Rooms-likes

Field notes template. Play (or watch no-commentary playthroughs of) each
game and fill in observations. The goal is to learn the genre's shared
grammar — adopt it freely, it's the alphabet, not theft — and to map the
gaps where *Soul Game* is different on purpose.

Games: **Rooms** (the minimalist original), **Doors** (the polished
standard), **Grace** (modern darkness/light-focused take), **Pressure**
(the direct inspiration), plus anything else similar.

---

## Questions to answer per game

### Room grammar
- How many distinct room *templates* does an average run seem to use?
- How are templates varied? (mirroring, decoration swaps, lighting)
- Size rhythm: corridor → large room → tight room — what's the pattern?
- How often does a "rest" room appear (no threat possible / shop / loot)?

### Telegraphs & entities
- For each common entity: what is the tell, which *sense* carries it
  (audio / light / visual), and how many seconds between tell and threat?
- Can a new player survive their first encounter with no prior knowledge?
  If yes, what made it fair? If no, is dying the intended lesson?
  (Ours must differ: death teaches *nothing* — the witness rule.)

### The hide verb
- What is the hiding interaction (lockers, under beds, behind cover)?
- What limits it (time inside, entity that punishes hiding, spacing)?
- *Ours to design:* the garden equivalents — pocketing your flame +
  physical hiding spots (gazebo, benches, hedge alcoves)?

### Pacing & session
- Threat events per 10 rooms, roughly?
- Run length to first major landmark; total run length?
- What breaks tension on purpose (shops, jokes, safe NPCs), and how often?

### Onboarding
- How do the first ~10 rooms teach the mechanics without tutorial text?
- What is the very first threat, and why is it the right teacher?

### Death & retry
- What persists after death? (knowledge, currency, items, nothing)
- How fast is death → back in a run? Does the lobby do anything?

### Identity
- In one sentence: what is this game's *thing* that the others lack?

## The gap map (why Soul Game exists)

Things none of the references do — our novelty budget is spent here, which
is why we can be conventional everywhere above:

1. **The return trip.** All references are one-way. Our second act —
   carrying the flame back — has no genre precedent to copy, so it needs
   the most original design attention.
2. **The witness rule.** References teach through death (auto-documents).
   For us, death teaches nothing; testimony must come home alive.
3. **Rekindling.** A revive that is a candle relit blue — rescue as a
   deliberate, costly procedure, not a mechanic footnote.
4. **The communal Refuge.** A hub that is a living, permanent progress
   meter (candles, memorial, records) rather than a matchmaking room.
